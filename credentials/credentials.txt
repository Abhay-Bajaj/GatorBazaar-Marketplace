	To access the EC2 server, download the repository locally. Once in the repository,
	you can access the server with the SSH key located in the credentials folder. Make sure
	that the SSH key is not public on your local repository:
	
	chmod 400 ./credentials/t3-instance-key.pem
	
	Then run the following command to connect to the server:

	ssh -i "./credentials/t3-instance-key.pem" ubuntu@ec2-3-128-247-244.us-east-2.compute.amazonaws.com
	
	To access the mySql database connected to the server, you'll need to input both 
	the database username and password:
	
	sudo mysql -u team07 -p
	
	this will promp you for the password. Type team07 and you'll gain access to the database
	that is currently set up.
